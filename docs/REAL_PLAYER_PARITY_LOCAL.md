# تشغيل فحص مطابقة اللاعب الحقيقي محلياً

يمكن تشغيل فحص المطابقة دون دمج PR #7 أو نشر الموقع على Pages. لا تحتاج إلى إرسال كلمة المرور أو Firebase ID token إلى أي شخص؛ تسجيل الدخول يتم داخل متصفحك.

## الخطوات

```bash
git clone https://github.com/luffyk124-del/nexora-game.git
cd nexora-game
git checkout feature/nexora-social-economy-mobile-overhaul
npm install --no-audit --no-fund --package-lock=false
npm run dev
```

افتح `http://localhost:3000/?migration=1`، وسجّل الدخول بحساب Firebase الحقيقي الموثّق الذي يحتوي بيانات اللاعب. اضغط **تشغيل فحص المطابقة الآن**.

الفحص قراءة فقط؛ يقارن بيانات Firestore وSupabase لنفس UID. شغّله عندما لا تكون تنفّذ عمليات شراء أو تحويل أو مزاد في تبويب آخر، لتقليل اختلافات التوقيت. لا ترسل أي token أو كلمة مرور؛ يكفي إرسال أسماء الأقسام التي ظهرت فيها «اختلاف» أو لقطة للنتيجة بعد إخفاء البريد وUID.

تم السماح مؤقتاً بأصلَي التطوير المحلي `http://localhost:3000` و`http://127.0.0.1:3000` في CORS لوظيفة قراءة بيانات اللاعب فقط. لا تُفعّل مفاتيح تحويل القراءات أثناء هذا الاختبار.
